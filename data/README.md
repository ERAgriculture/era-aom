# Data

Canonical normalized sources will live here after migration and cutover.

Planned logical entities include schemes, concepts, labels, definitions,
relations, mappings, history, sources, code lists, crosswalks, and data-model
tables.

Current workbook remains outside Git. Never add closed or unreviewed workbook
content directly.

`registry-bindings/` contains governed public semantic-binding source rows and
append-only binding IDs. It references private `era-data` registry subjects by
stable ID and row checksum without copying private registry definitions.

`pilot/` contains normalized AOM crop `prac` and `out` sources for architecture
validation. Existing livestock AOM remains a separate module pending inventory
and comparison. Workbook remains canonical.
