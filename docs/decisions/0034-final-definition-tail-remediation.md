# ADR 0034: Final definition-tail remediation

- Status: accepted
- Date: 2026-08-06
- Owner: Alliance of Bioversity International and CIAT
- Reviewer: TBD

## Decision

Treat all 109 remaining definition gaps as one governed remediation portfolio,
not as a stream of convenient term-sized approvals. Route each concept to one
of seven review tracks and require explicit evidence gates before promotion.

No remaining concept is eligible for automatic approval. Identity collisions
require occurrence audits and replacement direction; material-scope cases need
direct material-grade evidence; derived descriptors need approved semantic
facets; commercial products need stable manufacturer/formulation evidence; and
local terms need study-level provenance. Existing raw labels and identifiers
remain preserved while held.

This register is decision support, not semantic publication. Reviewed approvals
must enter a later promotion batch with source evidence, replacement provenance,
regenerated distributions, and validation.
