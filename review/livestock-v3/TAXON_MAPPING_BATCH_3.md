Batch covers twenty-one high-impact unresolved source names using live NCBI
Taxonomy evidence. It exposes two incorrect legacy identifiers:

  replacement is `NCBITaxon_145622`.
- `Psophocarpus tetragonolobus` points to `NCBITaxon_3847` (`Glycine max`);
  proposed replacement is `NCBITaxon_3891`.

Source text remains unchanged. Accepted-name fields separately normalize
`Opuntia ficus indica`, misspelled `Gliciridia sepium`, and synonym
`Pennisetum clandestinum`. These normalizations must not become fuzzy-matching
rules. `Saccharomyces cerevisiae` is intentionally included as a fungal taxon;
WFO does not apply. All other WFO reconciliation remains deferred.

Approval requires checking live evidence and confirming each source label
represents organism identity rather than material text.
