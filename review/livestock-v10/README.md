# Feedipedia semantic promotion review

Eight exact-label candidates from livestock-v9 received source/component/process
review. Six have enough evidence for structured definitions. Two remain held
because source-level evidence does not identify feed-material component.

Review applies data-module contract:

- source identity remains independent;
- anatomical part or material component uses dedicated property;
- processing method is asserted only when evidenced;
- form, product role, integrity, composition, and constituent remain separate;
- ingestion consumes assertions, never reparses preferred labels;
- Feedipedia co-reference does not create AOM synonyms.

No ILRI feed code participates in decision.
