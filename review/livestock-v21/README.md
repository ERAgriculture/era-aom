# Material-scope closure

Complete review of 40 final-tail material-scope concepts. Canonical AOM workbook
identity and hierarchy establish operational feed-material scope. Definitions
remain deliberately bounded: component, whole-material integrity, processing,
form, composition, and nutritional properties stay unspecified unless explicit
approved facets exist.

This prevents taxon-to-whole-plant inference while allowing useful source-scope
definitions. External mappings remain related evidence and do not determine
definition wording.
