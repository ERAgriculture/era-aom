# Canonical-workbook model-gap review

Frozen cohort covers 23 concepts whose only stable evidence is canonical
workbook identity and hierarchy. Decisions separate safe structural material
semantics from branded products, local names, and hierarchy defects.

Four concepts receive definitions from workbook identity plus existing facets:
two named binders, mixed marine hydrolysate, and Cheka residue. Nineteen remain
held. Commercial products require external composition/manufacturer evidence;
local names require domain identity evidence. `Lactobacillus plantarum` remains
held pending correction from prebiotic hierarchy to governed microbial/probiotic
semantics. ILRI feed codes are excluded.

Rebuild review ledger:

```sh
python scripts/build_workbook_model_gap_review.py
```
