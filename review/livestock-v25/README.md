# Livestock v25 — global identity-integrity remediation

Skosmos visual review exposed concept identity problems not covered by earlier
family-specific gates. This cohort audits every normalized duplicate preferred
label across full livestock scheme before any further concept allocation or
publication work.

Artifacts generated by `scripts/build_global_identity_audit.py`:

- `global_identity_collision_cohort.csv` — one review decision per collision;
- `global_identity_collision_detail.csv` — hierarchy, type, definition, origin,
  and semantic-use evidence for every involved concept;
- `global_identity_collision_summary.json` — regression baseline.

`proposed` rows are not semantic approvals. Reviewer must choose reuse/deprecate,
justified distinct meaning, or hold. Same label in different property context is
not enough evidence for distinct identity. Remediation must preserve identifiers,
publish replacement crosswalks, and keep legacy labels searchable.
