# Definition-gap classification

This packet classifies all 888 active definition gaps remaining after ADR 0022.

- `definition_gap_queue.csv` records domain, public mapping evidence, route, and status.
- `definition_gap_summary.json` provides workload totals.

Approved structural definitions use hierarchy and model role only. Feed-material
definitions remain research-required because taxon identity or broad external
mapping does not establish material scope. ILRI identifiers are excluded from
public evidence routing. Management and Farming System roots require manual core
definitions.
