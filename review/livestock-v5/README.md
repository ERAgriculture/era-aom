# Ingredient harmonization workbench

Generated by:

```bash
python scripts/build_ingredient_harmonization_workbench.py
```

Outputs cover all 1,643 governed feed-ingredient concepts (1,644 source
occurrences; known duplicate-ID occurrence resolved through normalized path):

- `ingredient_rule_catalog.csv` — reusable lexical rules and safety constraints;
- `ingredient_harmonization_inventory.csv` — proposed decomposition and route;
- `ingredient_signature_clusters.csv` — family review groups, never automatic merges;
- `ingredient_exception_queue.csv` — unresolved expert-only cases;
- `ingredient_harmonization_summary.json` — workload and safety metrics.

Workflow: approve rules in bulk, review signature clusters by family, then inspect
only remaining exceptions. These files are proposals; approved ontology changes
must be recorded separately in governed staging tables.
