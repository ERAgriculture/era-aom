# Full-cohort Feedipedia source-scope review

This cohort is fixed as frozen livestock-v9 Feedipedia evidence minus six
livestock-v10 semantic promotions. It never derives membership from generated
definition-gap output. Healthy, unshared pages may support source/material scope when
page heading directly contains AOM preferred identity. They do not transfer
narrower page descriptors into AOM.

Approved definitions state governed identity and explicitly leave component,
process, form, product role, integrity, composition, and constituent unspecified
unless separate assertions exist. Shared pages, warned pages, category lists,
retrieval failures, aliases, and mismatches remain held in same ledger.

Rebuild:

```sh
python scripts/build_feedipedia_source_scope_review.py
```

No ILRI feed code participates.
