# Release-readiness reviewer pack

Decision sheet for 18 integrity holds remaining after definition-tail closure.
Each row exposes semantic risk, candidate related IDs, accepted decision values,
evidence gate, and exact next action. Empty reviewer/decision fields are
intentional: release candidate may remain noncanonical with documented holds,
but no held concept may be silently promoted.

`release_readiness_summary.json` separates automated local acceptance, manual
visual acceptance, hosting, and canonical cutover. Local technical success does
not authorize public deployment or canonical cutover.
